# 🚀 Installation & Setup

## Backend Setup

```bash
cd backend
npm install
npm run dev
```

## Frontend Setup

```bash
cd frontend
npm install
npm start
```

---

# ⚙️ Environment Variables

Create a `.env` file inside backend:

```env
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key
GROQ_API_KEY=your_groq_api_key
```
